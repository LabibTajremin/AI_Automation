# Transcript to Follow-up Email

Paste a sales call or meeting transcript, get a drafted follow-up email with summary,
next steps, and a call to action — powered by Gemini's free API tier.

Target audience: sales reps, account managers, consultants, freelancers who do a lot of
client calls and want to skip writing follow-ups by hand.

## Setup (free)

1. Get a free Gemini API key: https://aistudio.google.com/app/apikey
2. `npm install`
3. `cp .env.example .env` and paste your key in
4. `npm start`
5. Open http://localhost:3002
